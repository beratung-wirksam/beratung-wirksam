## GitHub Pages aktualisieren
1. ZIP entpacken.
2. Das bestehende GitHub-Repository öffnen.
3. **Add file → Upload files**.
4. Den gesamten Inhalt dieses Ordners hochladen und bestehende Dateien ersetzen.
5. Commit-Nachricht z. B. `WIRKSAM Website Update 08-09-2026`.
6. Unter **Settings → Pages** prüfen:
   - Branch: `main`
   - Ordner: `/(root)`
   - Custom domain: `beratung-wirksam.de`
   - HTTPS erzwingen/Enforce HTTPS: aktiviert, sobald verfügbar.
7. Nach dem Deployment `https://beratung-wirksam.de` mit Strg+F5 neu laden.
